# brzezina.dev

Personal portfolio site — built with Next.js, TypeScript, and Emotion CSS-in-JS. Hosted on Vercel.

## Stack

- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Emotion CSS-in-JS
- **Hosting**: Vercel
- **Analytics**: Vercel Analytics + GA4

## Development

```bash
npm install
npm run dev
```
